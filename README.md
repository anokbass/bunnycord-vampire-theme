# Vampire — Noite Rubi

Tema para Bunny, com estética vampiresca em preto, cinza e vermelho rubi. Textos principais claros e botão principal branco para destacar o envio de mensagens.

## Instalação

1. Copie o link direto do arquivo `vampire.json`.
2. No Bunny, abra **Configurações → Bunny → Temas**.
3. Toque em **+**, cole o link e selecione **Install**.
4. Ative **Vampire — Noite Rubi** na lista de temas.

**Link de instalação:** `https://raw.githubusercontent.com/anokbass/bunnycord-vampire-theme/main/vampire.json`

O tema usa o formato JSON `spec: 2` aceito por temas Bunny/Vendetta. Algumas cores de ícones podem depender do plugin Themes+.

## Paleta

- Fundo: `#0b0a0c`, `#111013`, `#19171a`
- Cinzas: `#514b52`, `#928a90`, `#c9c2c7`
- Rubi: `#8e1428`, `#c51e3a`, `#e33b53`
- Texto e botão principal: `#f5f2f3`

## Compatibilidade

Criado para clientes que aceitam temas Bunny no formato de link JSON direto. O nome “Bunnycord” pode se referir a uma distribuição ou fork específico; caso esse cliente tenha um sistema de temas diferente, o importador pode não aceitar este arquivo.
