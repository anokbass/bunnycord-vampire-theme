# Vampire — Noite Rubi

Tema de alto contraste para Bunny, com uma paleta gótica contida: preto profundo, carvão e cinzas frios, rubi como acento e branco suave para textos. A hierarquia visual mantém superfícies escuras e reserva o vermelho para links, seleções e estados importantes.

## Instalação

1. Copie o link direto do arquivo `vampire.json`.
2. No Bunny, abra **Configurações → Bunny → Temas**.
3. Toque em **+**, cole o link e toque em **Install**.
4. Ative **Vampire — Noite Rubi** na lista de temas.

**Link para instalar:** <https://raw.githubusercontent.com/anokbass/bunnycord-vampire-theme/main/vampire.json>

## O que foi refinado

- Botões primários e de envio têm fundo branco suave e conteúdo escuro. Os textos e ícones não ficam brancos sobre branco.
- O contraste continua coerente nos estados pressionados, alternativos e secundários.
- Os componentes usam tons coordenados de preto, cinza, rubi e branco; cores padrão azuis, verdes e amarelas foram harmonizadas para não destoar.
- Menções, seleções, bordas, campos de texto, cartões e barras de rolagem têm cores próprias para manter uma interface consistente.
